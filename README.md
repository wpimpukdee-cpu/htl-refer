# ศูนย์ Refer และ พขร. · โรงพยาบาลห้วยแถลง

หน้าเปิดระบบสำหรับเพิ่มไอคอนลงหน้าจอมือถือ (iPhone / Android) และเข้าสู่ระบบ: เลือกชื่อ + PIN ที่หน้านี้ แล้วระบบพาเข้า HUB ศูนย์ Refer (Google Apps Script) โดยไม่ต้องใส่ PIN ซ้ำ

หน้านี้ไม่มีรายชื่อหรือรหัสใด ๆ เก็บไว้ในไฟล์ รายชื่อโหลดจากระบบตอนเปิดหน้า และ PIN ตรวจที่ระบบ (Apps Script) เท่านั้น

เปิดใช้งาน: https://wpimpukdee-cpu.github.io/htl-refer/
